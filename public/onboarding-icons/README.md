These harness icons are copied from hosted Cloud
(`cloud/packages/web/public/onboarding-icons`), which renders them from the
same artwork as the agentrelay.com onboarding preview. Only the harness icons
the dashboard shows are bundled here:

- Claude, Codex, Gemini: `@lobehub/icons` 5.10.0, `Color` components.
- Cursor, Grok, OpenCode: `@lobehub/icons` 5.10.0, `Mono` components.
- ChatGPT: `@lobehub/icons` 5.10.0 `OpenAI` `Mono` component (Grok Bot reuses Grok).
- MCP client: `@lobehub/icons` 5.10.0 `Mcp` `Mono` component.
- Devin, Muse: Cloud's own harness icons from the same set.
- Capy: the same artwork as Agent Relay Desktop's
  `macos/Sources/RelayDesktop/Resources/capy.svg`.
