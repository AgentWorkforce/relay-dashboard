These SVGs are rendered from the same icons as the agentrelay.com onboarding
preview, without adding an icon package to Cloud's browser bundle:

- Claude, Codex, and Gemini: `@lobehub/icons` 5.10.0, `Color` components.
- Cursor, Grok, and OpenCode: `@lobehub/icons` 5.10.0, `Mono` components.
- ChatGPT: `@lobehub/icons` 5.10.0 `OpenAI` `Mono` component (Grok Bot reuses Grok).
- MCP client: `@lobehub/icons` 5.10.0 `Mcp` `Mono` component.
- GitHub, Linear, Shortcut, Jira, Markdown: `react-icons/si` (Simple Icons),
  with the marketing preview's colors.
- Slack: the marketing site's `public/integration-logos/slack.svg`.
- GitLab: the paths of Cloud's own `app/components/GitLabLogo.tsx`.
- Capy: the same artwork as Agent Relay Desktop's
  `macos/Sources/RelayDesktop/Resources/capy.svg`.
